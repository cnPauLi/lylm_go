# 加密组（Pwd）域 API

管理链接访问控制所用的加密组（后台「加密组管理」对应能力），共 4 个端点。

## 通用约定

- Base URL：`/api/v1`
- 鉴权：全部端点需在请求头携带 `Authorization: Bearer sk-...`；缺失或无效返回 `401`。
- 统一响应信封：

```json
{ "code": 200, "message": "ok", "data": {} }
```

失败时 HTTP 状态码与业务 `code` 一致，`data` 为 `null`。
- 通用错误码：`400` 参数校验失败、`401` 未鉴权/密钥无效、`404` 记录不存在、`429` 触发限流、`500` 服务器内部错误。

## Pwd 对象字段

| 字段 | 类型 | 含义 |
|------|------|------|
| pwd_id | int | 加密组 ID |
| pwd_name | string | 加密组名称 |
| pwd_key | string | 访问密码（访问口令） |
| pwd_ps | string | 密码提示语 |

---

## 1. 获取加密组列表

- **用途**：返回全部加密组。
- **方法路径**：`GET /pwd`
- **鉴权**：需要。

### 入参

无（无查询参数、无请求体）。

### 出参

`data` 为对象：

| 字段 | 类型 | 含义 |
|------|------|------|
| list | Pwd[] | 加密组列表 |
| total | int | 记录总数 |

### 错误码

`401`、`429`、`500`。

### 请求示例

```http
GET /api/v1/pwd
Authorization: Bearer sk-xxxxxxxx
```

### 响应示例

```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "list": [
      {
        "pwd_id": 1,
        "pwd_name": "私密分组",
        "pwd_key": "secret",
        "pwd_ps": "访问提示"
      }
    ],
    "total": 1
  }
}
```

## 2. 新增加密组

- **用途**：新增一个加密组。
- **方法路径**：`POST /pwd`
- **鉴权**：需要。

### 入参（请求体，JSON）

| 名 | 类型 | 必填 | 长度/取值 | 含义 |
|----|------|------|-----------|------|
| name | string | 是 | 1–30 字符 | 加密组名称（trim 后不可为空） |
| key | string | 是 | 1–60 字符 | 访问密码（trim 后不可为空） |
| ps | string | 否 | ≤ 60 字符 | 密码提示语 |

### 出参

`data` 为创建后的 [Pwd 对象](#pwd-对象字段)。

### 错误码

| 码 | 触发条件 |
|----|----------|
| 400 | 缺少 name/key、字段超长、请求体非合法 JSON |
| 401 | 未鉴权/密钥无效 |
| 429 | 触发限流 |
| 500 | 服务器内部错误 |

### 请求示例

```http
POST /api/v1/pwd
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json

{
  "name": "私密分组",
  "key": "secret",
  "ps": "访问提示"
}
```

### 响应示例

```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "pwd_id": 1,
    "pwd_name": "私密分组",
    "pwd_key": "secret",
    "pwd_ps": "访问提示"
  }
}
```

---

## 3. 修改加密组

- **用途**：按 ID 修改加密组全部字段（全量更新）。
- **方法路径**：`PUT /pwd/{id}`
- **鉴权**：需要。

### 入参

路径参数：

| 名 | 位置 | 类型 | 必填 | 说明 |
|----|------|------|------|------|
| id | path | int | 是 | 加密组 ID，正整数 |

请求体：与 [新增](#2-新增加密组)完全一致（name/key 必填）。

### 出参

`data` 为修改后的 [Pwd 对象](#pwd-对象字段)。

### 错误码

| 码 | 触发条件 |
|----|----------|
| 400 | id 非正整数，或请求体校验失败（同新增） |
| 401 | 未鉴权/密钥无效 |
| 404 | 指定 id 的加密组不存在 |
| 429 | 触发限流 |
| 500 | 服务器内部错误 |

### 请求示例

```http
PUT /api/v1/pwd/1
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json

{
  "name": "私密分组2",
  "key": "secret2",
  "ps": "新提示"
}
```

### 响应示例

```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "pwd_id": 1,
    "pwd_name": "私密分组2",
    "pwd_key": "secret2",
    "pwd_ps": "新提示"
  }
}
```

---

## 4. 删除加密组

- **用途**：按 ID 删除一个加密组。
- **方法路径**：`DELETE /pwd/{id}`
- **鉴权**：需要。

### 入参

| 名 | 位置 | 类型 | 必填 | 说明 |
|----|------|------|------|------|
| id | path | int | 是 | 加密组 ID，正整数 |

无请求体。

### 出参

`data` 为对象：

| 字段 | 类型 | 含义 |
|------|------|------|
| id | int | 被删除的加密组 ID |

### 错误码

| 码 | 触发条件 |
|----|----------|
| 400 | id 非正整数 |
| 401 | 未鉴权/密钥无效 |
| 404 | 指定 id 的加密组不存在 |
| 429 | 触发限流 |
| 500 | 服务器内部错误 |

### 请求示例

```http
DELETE /api/v1/pwd/1
Authorization: Bearer sk-xxxxxxxx
```

### 响应示例

```json
{
  "code": 200,
  "message": "ok",
  "data": { "id": 1 }
}
```
